# 一个月压缩路线：以求职作品为中心

你的教育背景并不是主要短板：华东理工智能制造本科 + 南洋理工 Computer Control & Automation 硕士，与机器人控制/算法方向是相容的。当前最大的风险是“会描述很多工具，但没有一个能运行、能解释、能复现的项目”。因此一个月只做一条主线。

## 第 1 周：传统 IK 基线与工程习惯

目标：RM 机械臂在 Isaac Sim 中跟随目标，项目可在另一台机器上按 README 复现。

- Linux/SSH、Git 基本循环。
- 坐标系、旋转矩阵/四元数、齐次变换。
- 正运动学、雅可比、解析/数值 IK、关节限制和奇异位形。
- 导入 RM URDF，完成 Lula IK。
- 生成 20～100 个可达目标，记录成功率和误差。

成果：传统 IK 视频 + 初版 README + 评估脚本。

## 第 2 周：运动规划与一个抓取闭环

目标：不是只“瞬移到答案”，而是安全地走到预抓取位姿并抓取一个方块。

- 理解 IK 与 motion planning 的区别。
- 用 RMPflow、RRT 或 cuRobo 中的一种生成无碰撞运动。
- 加入桌面、方块和夹爪开合状态机。
- 记录规划成功率、碰撞率和耗时。

成果：pick-and-place demo + 失败案例说明。

## 第 3 周：Isaac Lab 强化学习 reaching

目标：训练一个最小 RL reaching 策略，并与传统 IK 在固定目标集比较。

- 先改官方 reach 示例，不从空白环境开始。
- 观测：关节位置/速度、末端到目标的相对位姿。
- 动作：关节位置增量或关节速度。
- 奖励：距离、姿态、动作平滑、关节限制、成功奖励。
- 随机化目标；分训练集与未见测试集。

成果：训练曲线 + checkpoint 下载说明 + 对比表。大型 checkpoint 不直接塞进 Git。

## 第 4 周：求职包装与面试准备

目标：让招聘者在三分钟内看懂项目价值，并让你能独立回答追问。

- README：问题、方法、架构、安装、运行、结果、局限。
- 1～2 分钟视频：传统 IK、规划抓取、RL reaching、指标对比。
- 一页项目讲稿：为什么做、遇到的最大 bug、如何验证、下一步。
- 补 ROS 2 的 node/topic/service/action、launch、TF2、URDF/MoveIt 2 概念。
- 准备 2～3 道代码题和机器人基础问答，不追求题量。

## 每日时间分配（全职学习版本）

- 3 小时：主项目实现与排错。
- 1.5 小时：运动学/规划/RL 的定向理论。
- 1 小时：Python/C++ 与数据结构基本功。
- 0.5 小时：整理 Git 提交、实验记录、次日任务。

如果每天只有 3 小时，按比例缩减，但保持项目时间不少于一半。

## 一个月后的合理定位

一个月不足以成为成熟的具身智能研究算法工程师，但足以形成下面这种可信定位：

> 机器人 manipulation / 运动规划方向的应届或实习候选人，能在仿真中完成机械臂建模、IK、基础规划、RL reaching，并具备 Linux、Git、Python 和 ROS 2 的入门工程能力。

优先投递：机器人算法实习、仿真算法、机械臂应用算法、运动规划/控制助理工程师、具身智能数据与仿真岗位。对纯研究型 RL/模仿学习、大模型机器人基础模型岗位，可以投但不作为唯一目标。
