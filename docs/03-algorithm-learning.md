# 机器人算法知识地图与 LeetCode 建议

## “算法”到底是什么

算法是一套把输入变成输出、并能分析正确性与代价的明确步骤。它不等于 LeetCode，也不等于人工智能。

- 排序、二分、图搜索：通用计算机算法。
- IK、A*、RRT、轨迹优化、卡尔曼滤波：机器人算法。
- PPO、SAC、行为克隆：学习算法。

它们不冲突。通用数据结构和算法提供编程基本功；机器人算法使用线性代数、几何、优化、概率和控制解决物理世界问题。

## 是否需要刷 LeetCode

需要，但只刷到“面试和工程够用”，不要在这一个月把它当主线。建议 20～30 道高频基础题，而不是 200 道。

优先主题：

1. 数组、字符串、哈希表。
2. 栈、队列、链表。
3. 二分查找、排序、双指针。
4. 树的 DFS/BFS。
5. 图的 BFS/DFS、最短路基本思想。
6. 基本复杂度分析。

暂缓：困难动态规划、竞赛技巧、冷门数据结构。除非目标岗位笔试明确要求，否则它们对当前项目回报很低。

## 机器人 manipulation 的核心学习顺序

### 第一层：马上补

- Python：函数、类、模块、虚拟环境、NumPy、调试和异常。
- Linux：路径、权限、进程、环境变量、SSH、日志。
- Git：status/diff/add/commit/push/branch。
- 数学：向量矩阵、坐标变换、旋转矩阵、四元数、导数与雅可比。

### 第二层：项目中补

- 运动学：DH 或 product of exponentials、FK、IK、Jacobian、奇异性。
- 规划：配置空间、碰撞检测、A*、RRT/RRT*、轨迹参数化。
- 控制：PID、关节空间/任务空间控制、阻抗控制基本概念。
- ROS 2：node、topic、service、action、launch、TF2、URDF、rosbag。

### 第三层：形成竞争力

- 优化：最小二乘、约束优化、轨迹优化、MPC 基本思想。
- 概率：高斯分布、贝叶斯、Kalman filter、采样。
- 机器学习：PyTorch、监督学习、训练/验证划分、过拟合。
- 强化学习：MDP、value/policy、PPO/SAC、reward design、sim-to-real。
- 感知抓取：相机标定、点云、位姿估计、grasp pose generation。

## AI 辅助开发的正确目标

你不需要坚持“每一行都从空白手写”，但要从“AI 代做”升级到“你负责系统设计、验证与排错”。每次接受代码前问五件事：

1. 这个函数的输入输出是什么？
2. 坐标系、单位和 shape 是什么？
3. 失败时会返回什么？
4. 如何做一个最小验证？
5. 换一台机器需要哪些依赖和配置？

在机器人项目里，最危险的错误往往不是语法错误，而是代码能跑但坐标系、单位、关节顺序或物理假设错了。
