# 变更记录

## 2026-09-28 — 修正无关 scripted IK 假拒绝并发现视觉重复性缺口

- Git 提交 `c707b7d`：pi0.5 模式跳过不会执行的 scripted 放置 IK 预计算，scripted 模式的 0.75 rad 安全阈值保持不变；
- 4 个原被误拦截案例各自第一次真实策略执行为 3/4，通过后与其余 56 例合成主审计结果 54/60（90%）；
- 正式复现运行得到 55/60（91.7%），60/60 报告齐全、零真机命令；
- `robust_042` 在相同 checkpoint、策略 seed 和仿真 seed 下由失败翻转为成功；
- 逐块哈希定位：初始关节/夹爪与显式噪声 4/4 一致，双相机首帧和首动作 0/4 一致；
- 新增首次执行纠正证据生成器、重复性审计器及 17 项单元测试；
- 结论调整为“仿真点估计门槛通过，但端到端重复性未验证”，真机门禁继续关闭。

## 2026-09-28 — 完成 60-case 评测并修复门禁漏洞

- 正式结果 51/60（85%），60/60 报告齐全，全部仿真、零真机命令；
- 内圈/中圈/外圈分别为 19/20、18/20、14/20；
- 发现旧 suite 在缺 4 份报告时仍会因有效报告数大于 20 而误判通过；
- 修复为“最小样本数 + 全部计划报告齐全 + 成功率”三项同时满足；
- 将当时观察到的 IK 分支跳变转换为结构化预执行安全失败；后续代码审计确认该轨迹在 pi0.5 分支不会执行，并在下一条记录中修正；
- 相关单元测试、单案例集成测试和恢复运行均通过；
- 生成紧凑证据、Wilson 置信区间、分层失败分类和释放分析。
