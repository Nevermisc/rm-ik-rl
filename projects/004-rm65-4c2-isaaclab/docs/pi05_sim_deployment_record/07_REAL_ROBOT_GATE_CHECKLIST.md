## 解锁顺序

```text
只读硬件审计
  → 关节反馈探针
  → 相机与夹爪标定
  → pi0.5 影子模式（只记录建议动作）
  → 空工作区单关节极小步
  → 六轴低速已知轨迹
  → pi0.5 空载、夹爪保持张开
  → 轻质软物低速抓取
  → 完整抓放统计
```

任何阶段只要出现通信超时、时间戳过期、非有限值、关节顺序不一致、人员离场或急停不可用，就回到阻塞状态。

## 真机首次运动前必须人工确认

- 示教器显示的机械臂 IP 与配置一致；
- 电脑网口地址不冲突且仅连接预期控制网段；
- 硬件急停触手可及并已实际测试；
- 工作区无人、无障碍物；
- 机械臂处于低速模式；
- 夹爪中没有硬质危险物；
- 操作者理解本次最大关节变化和停止方法。

这些确认不能由本项目自动推断，也不能因为仿真达到 80% 而省略。
